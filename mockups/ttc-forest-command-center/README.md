# TTC Forest Command Center

Interactive UI mockup for visualizing how The Trading Council converts individual Member-model ballots into a governed trading verdict.

## Live mockup

https://ttc-forest-command.beldwin995613.chatgpt.site

## What the mockup demonstrates

- A 40-Member bot/model forest
- Clickable inspection of each Member's vote, confidence, grove, and primary features
- `LONG`, `SHORT`, and `ABSTAIN` ballot states
- Ranger regime classification
- Council vote aggregation
- Correlation and concentration penalties
- Raw consensus versus effective consensus
- Calibrated probability and net expectancy
- Guardian risk authorization
- Final Council verdict and position-size guidance
- Strong-long, divided-Council, and false-confidence simulations
- Responsive desktop and mobile behavior

## Source layout

- `app/page.tsx` — dashboard structure, Member forest, workflow, scenarios, and interactions
- `app/globals.css` — complete visual system and responsive layout
- `app/layout.tsx` — page metadata and root document

This is a product-design mockup using representative values. It is not connected to live market data, trained TTC artifacts, a portfolio, or a brokerage account.
